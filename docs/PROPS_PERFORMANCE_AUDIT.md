# Props Performance Audit

**Branch:** `cursor/post-a11y-gate` (base `cursor/away-a11y-perf` @ `62b598c`)  
**Measured:** 2026-09-10 via `node scripts/props-perf-bench.js` + `tests/a11y-props-images.test.js`  
**Method:** Synthetic fixtures only (filter → sectionize → HTML string build). Not a browser paint profile.

## Mechanism

- Threshold: `props.length >= 100` → `deferHeavy`
- First `_PB_PROP_EAGER_SECTIONS` (4) section bodies render eagerly
- Remaining section bodies stay in `<template class="mc-prop-deferred-tpl">` until IntersectionObserver hydrate (`_pbHydrateDeferredPropSections`)
- Full prop array remains in `_pbPropsCache` — filters/tabs operate on cache, not deferred DOM
- Bet slip resync via `_pbResyncBetSlipSelections` after render/hydrate; cell IDs from `_pbPropCellId` are stable
